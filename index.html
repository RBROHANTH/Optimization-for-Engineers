A. Part A theory: ready-to-write 2-mark answers

1. What is Operations Research (OR)?
OR is the scientific approach to decision making: it builds a mathematical model of a real system and finds the best (optimal) decision when resources are limited.
2. Applications of OR
Production planning and product mix · inventory control · transportation and assignment · queueing (banks, hospitals, networks) · scheduling and project management (PERT/CPM) · advertising-media selection · finance (portfolio, capital budgeting) · defence and logistics.
3. Mathematical formulation of an LPP CAT1 Q1
Optimise (Max or Min) Z = c₁x₁ + c₂x₂ + … + cₙxₙ
subject to aᵢ₁x₁ + aᵢ₂x₂ + … + aᵢₙxₙ (≤, = or ≥) bᵢ, i = 1, 2, …, m
and xⱼ ≥ 0, j = 1, …, n.
The parts are: decision variables xⱼ, the objective function, the constraints, and the non-negativity restrictions.
4. Advantages of LPP ESE Q1
(i) Gives insight into the problem and a clear picture of the true situation. (ii) Gives a scientific, mathematical analysis of the problem. (iii) Lets the decision maker frame strategies consistent with the constraints and objectives. (iv) Helps make the best use of scarce resources. (v) Makes re-evaluation easy when conditions change. (Any two are enough for 2 marks.)
5. Limitations of LPP
Assumes linearity · may give fractional answers · handles one objective only · parameters assumed certain (known constants) · large problems need a computer.
6. Slack and surplus variables ESE Q2CAT1 Q3
Slack sᵢ ≥ 0 is added to a “≤” constraint to make it an equation: Σaᵢⱼxⱼ + sᵢ = bᵢ. It is the unused resource.
Surplus sᵢ ≥ 0 is subtracted from a “≥” constraint: Σaᵢⱼxⱼ − sᵢ = bᵢ. It is the excess over the requirement.
7. Artificial variable
A non-negative variable Rᵢ added to “≥” and “=” constraints only to get a starting basic feasible solution. It has no physical meaning and is given a huge penalty (−M in Max, +M in Min) so it leaves the basis.
8. Feasible / basic / optimal solution CAT1 Q5
Feasible solution: any set of values satisfying all constraints and non-negativity.
Basic solution: put (n − m) variables = 0 and solve the m equations for the rest.
Basic feasible solution: a basic solution with all basic variables ≥ 0.
Optimal solution: a feasible solution that gives the best value of Z.
Degenerate: a basic variable equals 0.
9. Special cases
Infeasible: no point satisfies all constraints (graph: no common region; simplex: an artificial variable stays positive at the optimum).
Unbounded: Z can grow forever (simplex: the entering column has no positive entry).
Alternative optima: at the optimum some non-basic variable has Zⱼ−Cⱼ = 0 (graph: Z-line parallel to a binding edge).
10. Standard form of an LPP
(i) All constraints are equations (add slack / subtract surplus). (ii) All right-hand sides bᵢ ≥ 0 (multiply a row by −1 if needed). (iii) All variables ≥ 0. (iv) Objective is Max (Min Z = −Max(−Z)).

B. Formulation: step by step

  1. Identify the decision variables (what you can choose) and write “Let x₁ = …, x₂ = …”.
  2. Write the objective: profit → Max, cost → Min. Z = Σ (unit profit or cost) × variable.
  3. Write one constraint per resource or requirement: “available / at most” → ≤; “at least / minimum requirement” → ≥.
  4. Add non-negativity: x₁, x₂ ≥ 0.

C. Graphical method: step by step

  1. Formulate the LPP (if it is a word problem).
  2. Treat each constraint as an equation and find its two intercepts: put x₁=0 → x₂ value; put x₂=0 → x₁ value. Make a small table.
  3. Draw the axes with a suitable scale and draw every line.
  4. Shade the side each inequality allows (≤: towards origin; ≥: away from origin; test with (0,0)). The common shaded part in the first quadrant is the feasible region.
  5. Find every corner point: intercepts and intersections. Solve two equations at a time for intersections (elimination).
  6. Check each intersection satisfies all other constraints.
  7. Evaluate Z at every corner point in a table.
  8. Pick the largest (Max) or smallest (Min). Write the answer in words.
Special cases to recognise: no common region → infeasible. Region open upward with Max → unbounded. Region open upward with Min → the minimum still exists at a corner. Z-line parallel to a binding edge → alternative optima.

D. Simplex method (all constraints ≤): step by step

  1. Make every bᵢ ≥ 0. If the problem is Min Z, solve Max Z* = −Z.
  2. Add a slack sᵢ to each “≤” constraint; slacks get cost 0 in Z.
  3. Initial basic feasible solution: decision variables = 0, sᵢ = bᵢ.
  4. Draw the table: columns CB | YB (basic variables) | XB (their values) | one column per variable; write Cⱼ above.
  5. Compute Zⱼ − Cⱼ = Σ(CB × column entry) − Cⱼ for every column. Z = Σ CB·XB.
  6. Optimality test: if every Zⱼ − Cⱼ ≥ 0 → optimal, stop. Otherwise the most negative Zⱼ − Cⱼ gives the entering variable (key column).
  7. Ratio test: θ = XB ÷ key-column entry for positive entries only. The minimum θ gives the leaving variable (key row). No positive entry → unbounded.
  8. Pivot: key element = intersection. New key row = old key row ÷ key element. For each other row: new row = old row − (its key-column entry) × new key row. Replace CB and YB.
  9. Go back to step 5. At the end: basic variables = XB, all others = 0.

E. Big-M (penalty) method: step by step

  1. Make all bᵢ ≥ 0. For Min Z, solve Max Z* = −Z (this is safest; then Min Z = −Max Z*).
  2. Convert constraints: ≤ → + slack sᵢ. ≥ → − surplus sᵢ + artificial Rᵢ. = → + artificial Rᵢ.
  3. Objective: give every artificial the cost −M (in a Max problem). M is a very large positive number.
  4. Initial basis = all slacks and artificials (those with a +1 column).
  5. Compute Zⱼ − Cⱼ; they now look like (a·M + b). Compare using the M coefficient first; the most negative is the entering variable.
  6. Ratio test and pivot exactly as in simplex. Once an artificial leaves, you may delete its column.
  7. Stop when all Zⱼ − Cⱼ ≥ 0. If an artificial is still basic with a positive value → no feasible solution.

A. Part A theory

1. Integer programming problem (IPP)
An LPP in which some or all decision variables must take integer values. Example: number of machines, trucks or workers cannot be fractional.
2. Types of IPP CAT1 Q8
(i) Pure (all) integer: every variable must be an integer.
(ii) Mixed integer: only some variables must be integers, the rest are continuous.
(iii) Zero-one (binary): every variable is either 0 or 1.
3. Zero-one programming problem ESE Q3
If all the variables in the optimum solution of an IPP are allowed to take only the values 0 or 1 (a yes/no type decision), the problem is called a zero-one programming problem. Examples: capital budgeting (accept a project or not), assignment, facility location.
4. Importance / need of IPP CAT1 Q9
Many real decisions are indivisible (men, machines, vehicles, projects). Simply rounding the LP answer may give an infeasible or a non-optimal point, so special methods (cutting plane, branch & bound) are needed. Used in production scheduling, capital budgeting, travelling salesman, crew scheduling, plant location.
5. Mixed IPP · Pure vs mixed CAT2 Q1, Q2
Mixed IPP: only some variables are restricted to integers.
Pure IPPMixed IPP
All variables integerOnly some variables integer

6. Gomory’s cutting plane / fractional cut
An extra (secondary / Gomorian) constraint added to the optimal simplex table. It cuts off the current non-integer optimum but no feasible integer point; repeated cuts lead to the integer optimum.
7. Branch and bound technique ESE Q4
Starts with the continuous (LP) optimum, then systematically partitions the solution space into two sub-problems (xᵣ ≤ [xᵣ*] and xᵣ ≥ [xᵣ*]+1), eliminating the parts that contain no feasible integer solution. Nodes are fathomed when infeasible, integer, or not better than the best integer value found.

B. Gomory’s all-integer (fractional) cutting plane: step by step

  1. Ignore integrality. Write the standard form and solve by the simplex method.
  2. If every basic variable is an integer → that is the answer. Otherwise go on.
  3. Write every XBi = [XBi] + fᵢ, where [ ] is the integer part and 0 ≤ fᵢ < 1. Choose the row with the largest fᵢ = source row (tie → choose any).
  4. In the source row, write every coefficient as integer + non-negative fraction. A negative fraction becomes negative integer + positive fraction, e.g. −⅔ = −1 + ⅓, −¼ = −1 + ¾.
  5. Gomory cut: Σ fkj xⱼ ≥ fk (sum over non-basic variables), i.e. −Σ fkj xⱼ + s₁ = −fk, s₁ = Gomorian slack.
  6. Add this row at the bottom of the optimal table (s₁ is basic with a negative value → optimal but infeasible).
  7. Dual simplex: leaving variable = row with the most negative XB. Entering variable = Max{(Zⱼ−Cⱼ) ÷ arj : arj < 0}. Pivot as usual.
  8. Repeat steps 2–7 until all basic variables are integers.

D. Branch and bound: step by step

  1. Solve the LP relaxation (graphically for 2 variables). If the answer is integer → stop.
  2. Pick a fractional variable xᵣ = xᵣ* (e.g. the one with the largest fraction). Create two sub-problems: SP-a: xᵣ ≤ [xᵣ*] and SP-b: xᵣ ≥ [xᵣ*] + 1. This removes the strip [xᵣ*] < xᵣ < [xᵣ*]+1, which contains no integer point.

  4. Fathom (stop) a node if (a) it is infeasible, (b) its solution is all-integer (record it as a candidate), or (c) its Z is not better than the best integer Z found so far.
  5. Branch again on the remaining nodes.
  6. When every node is fathomed, the best candidate is the optimal integer solution. Draw the tree.

A. Part A theory

1. Dynamic programming ESE Q5CAT2 Q4
Dynamic programming is a mathematical technique of optimisation using a multistage decision process, in which a sequence of interrelated decisions has to be made. It decomposes the original problem in n variables into n sub-problems (stages), each in one variable, solved one stage after another until the final stage is reached.
2. Need for DP
(i) All the decisions of a combination must be specified. (ii) The optimal policy can be selected only after all the combinations are evaluated. DP avoids enumerating every combination.
3. Bellman’s principle of optimality CAT2 Q5★
“An optimal policy has the property that, whatever the initial state and initial decision are, the remaining decisions must constitute an optimal policy with regard to the state resulting from the first decision.”
4. Characteristics of DP ESE Q6CAT2 Q7★
(1) The problem can be divided into stages, with a policy decision required at each stage.
(2) Each stage has a number of states associated with it.
(3) The effect of the policy decision at each stage is to transform the current state into a state of the next stage.
(4) Given the current state, the optimal policy for the remaining stages is independent of the earlier decisions (Bellman).
(5) The solution moves stage by stage using a recursive relation.
5. Applications of DP CAT2 Q6
Production scheduling and employment smoothing · inventory levels and re-order policy · optimal combination of advertising media · shortest route / network problems · capital budgeting and allocation of resources · equipment replacement.
6. Forward vs backward computation CAT2 Q10
Forward: start at stage 1 and move to stage n; fₙ is built from f₁. Backward: start at the last stage n and move back to stage 1 (used for LPP by DP). Both give the same optimum; choose whichever makes the state definition easier.
7. When does y = f(x) attain a minimum? CAT2
At x = a where f′(a) = 0 and f″(a) > 0 (maximum if f″(a) < 0). This is the “usual classical method” used inside every DP stage below.
8. Key terms
Stage: a point where a decision is made · State: information needed at a stage (e.g. amount left) · Decision / policy: the choice made · Return: contribution to the objective · Recursive equation: links fₙ to fₙ₋₁.

B. Template for every “divide c into n parts” problem

  1. Define: “Let fₙ(c) be the maximum (or minimum) attainable value of … when c is divided into n parts y₁, …, yₙ. Each yᵢ is a stage.”
  2. n = 1 (one-stage problem): y₁ = c, so f₁(c) = (value with y₁ = c). This is trivial.
  3. n = 2: let y₁ = x, y₂ = c − x (or b/x for a product constraint). Write f₂(c) = opt0≤x≤c{ (term in x) ⊕ f₁(c − x) }.
  4. n = 3: y₁ = x and the rest (c − x) is split into 2 parts optimally → f₃(c) = opt{ (term in x) ⊕ f₂(c − x) }.
  5. General recursive equation: fₙ(c) = opt0≤x≤c{ (term in x) ⊕ fₙ₋₁(c − x) }.
  6. Solve n = 2: differentiate, set derivative = 0, find x, substitute → f₂ and the policy.
  7. Solve n = 3 the same way using the f₂ just found.
  8. Guess the pattern for n = m, then prove it holds for n = m + 1 (mathematical induction).
  9. State the optimal policy (y₁, …, yₙ) and the optimal value fₙ.

A. Part A theory

1. Characteristics of a queueing system
(1) Arrival pattern: customers arrive at mean rate λ (Poisson arrivals ⇔ exponential inter-arrival times).
(2) Service pattern: mean service rate μ (exponential service time with mean 1/μ).
(3) Number of servers (channels): single or multiple.
(4) System capacity: finite (N) or infinite (∞).
(5) Queue discipline: FIFO/FCFS, LIFO, SIRO (random), priority.
(6) Customer behaviour: balking (does not join a long queue), reneging (leaves after waiting), jockeying (switches queues), collusion.
2. Queue discipline ESE Q7
The queue discipline is the rule that decides the order in which waiting customers are selected for service, e.g. FIFO (first in first out), LIFO (last in first out), SIRO (service in random order) and priority service. It also covers how the queue forms and how customers behave while waiting.
3. Kendall’s notation ESE Q8CAT3 Q1★
A queueing model is written as (a / b / c) : (d / e), where
a = arrival (inter-arrival time) distribution · b = service-time distribution · c = number of servers · d = capacity of the system (max customers allowed) · e = queue discipline.
M = Markovian (Poisson arrivals / exponential service), D = deterministic (constant), G = general.
Example: (M/M/1):(∞/FIFO) = Poisson arrivals, exponential service, 1 server, infinite capacity, first-in-first-out.
4. Little’s formulae CAT3 Q3
Ls = λ·Ws · Lq = λ·Wq · Ws = Wq + 1/μ · Ls = Lq + λ/μ. For finite-capacity models replace λ by the effective rate λ′.
5. Traffic intensity (utilisation)
ρ = λ/(cμ) = fraction of time a server is busy. For infinite-capacity models a steady state needs ρ < 1.
6. Symbols
Ls = E(N) = average number in the system · Lq = E(Nq) = average number in the queue · Ws = E(W) = average time in the system · Wq = average time in the queue · P₀ = probability the system is empty · Pₙ = probability of n customers.
7. Transient vs steady state
Transient: probabilities depend on time (just after opening). Steady state: probabilities no longer change with time; all formulas here are steady-state.

  1. Identify the model: number of servers c (1 or more) and capacity (∞ or N). Write the Kendall notation.

  5. Compute the asked measure (Lq first is easiest for multi-server), then get the rest from Little’s formulae.

2. Lagrangian function ESE Q10
For optimising f(x) subject to h(x) = g(x) − b = 0, the Lagrangian is L(x, λ) = f(x) − λ·h(x) (one multiplier λᵢ per constraint: L = f − Σλᵢhᵢ). λ is the Lagrange multiplier; the necessary conditions are ∂L/∂xⱼ = 0 and ∂L/∂λ = 0.
3. Kuhn–Tucker conditions ESE Q9★
For Max f(x) subject to hᵢ(x) = gᵢ(x) − bᵢ ≤ 0, x ≥ 0:
(i) ∂f/∂xⱼ − Σᵢ λᵢ ∂hᵢ/∂xⱼ = 0, j = 1, …, n
(ii) λᵢ hᵢ(x) = 0 (complementary slackness)
(iii) hᵢ(x) ≤ 0
(iv) λᵢ ≥ 0
4. Sufficiency of Kuhn–Tucker conditions CAT3 Q9
For Max f(x) subject to hᵢ(x) ≤ 0, the KT conditions are also sufficient for a global maximum if f(x) is concave and every hᵢ(x) is convex (linear constraints are convex). For a minimisation, f must be convex (with the constraints written as ≥ type, or converted to Max −f).
5. Convex and concave functions
f is convex if f(θx + (1−θ)y) ≤ θf(x) + (1−θ)f(y) for 0 ≤ θ ≤ 1 (the chord lies above the curve). f is concave if −f is convex. A convex f has its stationary point as a minimum; a concave f gives a maximum.

C. Lagrange multiplier method (equality constraints): step by step

D. Kuhn–Tucker method (inequality constraints): step by step

  1. Bring the problem to Max f with ≤ constraints (Min f → Max −f; a “≥” constraint → multiply by −1).
  2. Write hᵢ(x) = gᵢ(x) − bᵢ ≤ 0.
  3. Write the KT conditions: ∂f/∂xⱼ − Σλᵢ∂hᵢ/∂xⱼ = 0; λᵢhᵢ = 0; hᵢ ≤ 0; λᵢ ≥ 0. (Equivalent slack form used in your key: L = f − Σλᵢ(hᵢ + sᵢ²), with ∂L/∂sᵢ = −2λᵢsᵢ = 0.)
  4. Case 1: λ = 0 (constraint not binding) → solve ∂f/∂xⱼ = 0. If the point satisfies h ≤ 0 → candidate found.
  5. Case 2: h = 0 (constraint binding, λ ≠ 0) → solve with the constraint as an equation; accept only if λ ≥ 0. With 2 constraints check 4 cases (λ₁ = λ₂ = 0; λ₁ = 0 only; λ₂ = 0 only; both binding).
  6. Sufficiency: show f is concave (AC − B² > 0, A < 0) and each h is convex (linear is fine) → the KT point is the global maximum.
  7. Compute Z.
